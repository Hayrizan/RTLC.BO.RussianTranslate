# RTLC.BO.RussianTranslate

Пользовательский русификатор для **Bō: Path of the Teal Lotus** (PC, Windows x64). Он добавляет русский отдельным языком, сохраняя английский и остальные языки игры.

## Скачать и установить

Скачайте [RTLC.BO.RussianTranslate.zip из первого публичного релиза](https://github.com/Hayrizan/RTLC.BO.RussianTranslate/releases/latest/download/RTLC.BO.RussianTranslate.zip). Закройте игру и распакуйте **содержимое** архива рядом с `Bo.exe`. В комплект входят BepInEx 5.4.23.2 x64 и плагин. При первом запуске русификатор выбирает русский; затем язык можно сменить в настройках игры.

Для удаления удалите `BepInEx/plugins/RTLC.BO.RussianTranslate`. BepInEx можно оставить, если он используется другими модами.

## Версия и совместимость

- Версия плагина: **1.0.20**.
- Проверено с PC-версией игры **1.2.7** и BepInEx **5.4.23.2 x64**.
- Установка содержит готовый `rtlc.bundle` с текстом, шрифтами и текстурами.
- Консоль BepInEx в комплекте отключена; журнал продолжает записываться в `BepInEx/LogOutput.log`.

## Редактирование перевода

`translation/RussianData.json` — таблица из опубликованного бандла. В каждой записи редактируйте поле `russian`, сохраняя `id`, `sourceEnglish` и адреса в `keys`, `dialogueTargets` и `actorTargets`.

Для локальной проверки включите `debugmode = true` в `BepInEx/config/com.rtlc.bo.russian-translation.cfg`. Плагин создаст рядом с DLL `RussianData.json`, если файла ещё нет, и будет перечитывать его после сохранения. Для обычной установки снова задайте `debugmode = false`; чтобы включить правки в новый релиз, пересоберите AssetBundle.

## Сборка плагина

Нужны .NET SDK, установленная PC-версия игры и BepInEx. DLL компилируется против библиотек игры и BepInEx, которые намеренно не входят в исходники:

```powershell
dotnet build .\src\BoRussian.csproj -p:GameDir="C:\путь\к\Bo"
```

AssetBundle для готового релиза собран Unity 2022.3. В репозитории нет исходных файлов пользовательских шрифтов и текстур; готовый бандл входит в ZIP из релиза.
